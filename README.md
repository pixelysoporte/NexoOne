# NexoOne

NexoOne es una app de entrenamiento personal que funciona en el navegador, en el móvil o en el ordenador:
un programa de musculación de 48 semanas, el **Pulso de hoy** (una orientación diaria según cómo estás),
bienestar y progreso.

- **Gratis y sin cuenta.** Todas las funciones están abiertas. No hay registro ni servidor.
- **Tus datos se quedan en tu dispositivo**, guardados en el navegador. Para no perderlos, exporta de vez
  en cuando una copia cifrada desde Ajustes → Privacidad y datos.
- **Se puede instalar como app** y funciona sin conexión una vez abierta. En iPhone, ábrela en Safari y
  pulsa Compartir → «Añadir a pantalla de inicio».
